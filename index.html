Featured: process-safety libraries on PyPI

A family of four PyPI packages, developed in one monorepo, launch-runner. They are built as ports and adapters, so code that asks for a process never depends on how it is started. Every operation returns an explicit result instead of raising, never flashes a Windows console window, decodes UTF-8, closes stdin unless text is supplied, and kills the whole process tree on timeout.

commandport

The contract: spec and result types, ports, in-memory fakes, and a scan (python -m commandport.scan) that fails the build when code bypasses subprocess. No dependencies.

lifecycle-runner

Run a command to completion with a time limit: capture it, stream it, or log it. Explicit results, never raises.

proclaunch

Start, stop and supervise long-running background processes with identity-checked records and readiness probes.

launch-runner

Meta-package that installs all three at matching versions.

pip install launch-runner
